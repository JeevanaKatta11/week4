# Sales Data Analysis Project

An end-to-end Python analysis of 100 sales transactions (Jan-Apr 2024): load, clean, analyse, visualise and report. Built for the **Option 4: E-commerce Sales Analysis** project brief.

## Project Overview

**Goal:** understand what drives revenue by looking at products, regions, time trends and order sizes, then turn the results into clear recommendations.

**Headline results**
- Total revenue **12.37M** from 478 units across 100 orders
- **Laptops** are the top product (31.5% of revenue); **North** is the top region (32.2%)
- **West** has a healthy order count but the lowest average order value
- The top 20% of orders produce 46.8% of revenue

Full write-up: [`report/Sales_Analysis_Report.pdf`](report/Sales_Analysis_Report.pdf) (also as `analysis_report.md`)

## Setup Instructions

1. Install Python 3.10 or newer.
2. (Recommended) create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the analysis:
   ```bash
   python main.py
   ```
   Optional: use a different file with `python main.py --data path/to/file.csv`.
5. Run the tests:
   ```bash
   python -m pytest -v
   ```

Outputs appear in `visualizations/` (charts), `report/` (summary tables) and `data/sales_data_clean.csv`.

## Technical Details

- **Cleaning:** trims/standardises text, parses dates and numbers, drops missing, duplicate and non-positive rows, and recomputes `Total_Sales` where it disagrees with `Quantity x Price`.
- **Analysis:** pandas `groupby` aggregations, month-over-month growth, product x region pivot table, Pareto concentration, Pearson correlation.
- **Error handling:** clear errors for a missing file, empty file, unparsable CSV and missing columns; `main.py` exits with a non-zero code and a readable message instead of a traceback.
- **Headless plotting:** uses matplotlib's `Agg` backend so it runs on servers and in CI.

## Data Limitations

Each customer appears once (no retention analysis), unit prices vary widely within each product, April is a partial month, and 100 rows is a small sample. See the report for details.
